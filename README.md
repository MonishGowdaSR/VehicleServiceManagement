# Vehicle Service Management and Operations Platform

## Project Overview

A full-stack MERN application developed to automate vehicle service center operations including booking, tracking, staff assignment, payment processing, and delivery management.

## Features

- User Authentication
- Vehicle Registration
- Service Booking
- Staff Assignment
- Live Vehicle Tracking
- Razorpay Payment Integration
- Invoice Generation
- Admin Dashboard
- Analytics

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- JWT Authentication

### Database
- MongoDB Atlas

### Maps
- React Leaflet
- OpenStreetMap

### Payments
- Razorpay

## Workflow

User Registration
→ Vehicle Registration
→ Service Booking
→ Staff Assignment
→ Live Tracking
→ Service Completion
→ Payment
→ Delivery
