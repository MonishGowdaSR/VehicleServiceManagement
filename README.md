# Vehicle Service Management and Operations Platform

## Overview

Vehicle Service Management and Operations Platform is a full-stack web application developed to streamline vehicle maintenance workflows for customers and service centers.

The platform enables customers to register vehicles, schedule service appointments, track service progress in real time, make secure online payments, and download digital invoices. Administrators can manage bookings, assign staff, monitor service operations, track payments, and analyze business performance through a centralized dashboard.

This project was developed as a Final Year Bachelor of Engineering project using the MERN Stack.

## Key Features

### Customer Module
- OTP-based user authentication
- Vehicle registration and management
- Driving license and vehicle image uploads
- Service booking with date validation
- Pickup and self-drop service options
- Real-time vehicle tracking
- Online payment integration using Razorpay
- PDF invoice and receipt generation
- Booking history and service status tracking

### Admin Module
- Secure admin authentication
- Booking management dashboard
- Staff assignment and service allocation
- Invoice generation system
- Payment monitoring and revenue tracking
- Customer management
- Analytics dashboard for service operations
